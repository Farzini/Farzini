# Hi, I'm Farzam

I'm a researcher working on **AI for optimisation and decision-making**, based in Porto, Portugal. My work sits between machine learning, operations research and engineering. I build methods that help systems make good decisions with limited data and expensive evaluations.

## Research interests

- Bayesian and multi-fidelity optimisation
- Safe, data-efficient learning for robotics
- Machine learning for logistics and last-mile delivery
- Operations research: routing, districting, mathematical programming
- High-performance and GPU computing for optimisation

## Selected projects

| Project | Summary |
|---|---|
| [Multi-Fidelity BO for Process Design](https://github.com/Farzini/multifidelity-bo-process-design) | Using cheap and expensive simulators together to optimise chemical processes |
| [Safe Learning for Robotic Assembly](https://github.com/Farzini/safe-bo-robotic-assembly-overview) | Data-efficient controller tuning under safety constraints |
| [Deep Learning for Last-Mile Delivery](https://github.com/Farzini/last-mile-district-sequencing) | Learning district visiting sequences and forecasting delivery demand |
| [Last-Mile Planning Toolkit](https://github.com/Farzini/last-mile-planning-toolkit) | Districting, distance prediction and route planning with an interactive interface |
